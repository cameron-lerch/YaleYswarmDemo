This was my first experience with the [Bitcraze Crazyflie 2.1](https://www.bitcraze.io/products/old-products/crazyflie-2-1/). I built this demo for the Intelligent Autonomy Lab to show prospective PhD students during their visit to Yale.

The lab had just opened, and the Crazyflies were delivered on a Thursday. Over the weekend I built and calibrated the swarm, learned how to fly them, and programmed this demo to run on Monday morning.

The drones' positions are hard-coded so that, viewed from the right angle, the swarm forms a "Y".

## Files

- `swarmY.py` – the demo script
- `example_code/` – Bitcraze example scripts used while learning
- `connect_log_param.py` – basic connection/logging test
